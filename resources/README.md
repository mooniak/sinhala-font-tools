# Resources

Reference material kept alongside the design models. None of it is generated
or consumed by the tools; the repo's GPL-3.0 licence does not cover the
third-party items listed below.

| Item | What it is | Source / licence |
|---|---|---|
| [`sinhala-anatomy-notes.pdf`](sinhala-anatomy-notes.pdf) | Annotated drawings of Sinhala letter groups: eye construction, stroke order, symmetry and alignment rules. Summarised in [`model/sinhala-anatomy.md`](../model/sinhala-anatomy.md) §5. | mooniak |
| [`Hodipotha-9.ttf`](Hodipotha-9.ttf) | Hodipotha, a reference Sinhala font. | © ICTA 2014, designed by E D Pemasiri & Dineesha Ediriweera; CC BY-ND 4.0 (per the font's name table) |
| [`sinhala-frequency-analysis/`](sinhala-frequency-analysis/) | Character-frequency report (`index.html`) and the newspaper text corpus it was computed from (`sinhala/Corpus/`, UTF-16). The counter script lived in mooniak/Frequency-Counter and is not vendored here. | Corpus: Sinhala newspaper text (e.g. Silumina, ANCL, 2004); check redistribution terms before reuse |
| [`sinhala-font-display-text-frequency.html`](sinhala-font-display-text-frequency.html) | Frequency report for the sample paragraph used in font displays. | mooniak |
