# Glyphs sidebar filters — GENERATED

Do not hand-edit. Regenerate with `node tools/glyphs-filters/build.js`.

Copy the `CustomFilter*.plist` file(s) next to a `.glyphs`/`.glyphspackage` file
(project-scoped) or into `~/Library/Application Support/Glyphs 3/` (global), then
restart Glyphs. The sidebar heading is whatever follows `CustomFilter` in the
filename; sections and groups appear as folders under it.

Model version 0.2.0. Glyph names are LankaGlyphSets `name-sinh`.
