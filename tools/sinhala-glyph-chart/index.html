About This Tool

This tool helps visualize and explore Sinhala compound letter combinations. It shows how consonants combine with vowel marks and special conjunct forms.

Copy Options

• Hover over any cell to see detailed Unicode information

• Click on any cell to copy that character combination

• Use the sorting options to reorganize the chart

• Use the copy buttons to copy different categories of combinations

• Drag and drop a Sinhala font file onto the page to test it

Regular Consonants - White background rows

Ligated Conjuncts - Light blue background rows (with ZWJ)

Touching Consonant Clusters - Light red background rows (common combinations)

The chart displays various ways these can combine with vowel marks.

Rakaransaya (්‍ර) - Compound form with a following "ra"

Repaya (ර්‍) - Compound form with a preceding "ra"

Yansaya (්‍ය) - Compound form with a following "ya"
